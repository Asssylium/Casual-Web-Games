# Memory Pass audio

Only these player-provided MP3 files are used by Memory Pass:

- `Opening sound for memory.mp3` — plays once when a player enters the Memory lobby.
- `Loose sound take 4 second.mp3` — plays when a player loses a point after a claim is resolved.
- `Memory Winning sound take 6 second.mp3` — plays when the match ends.

The in-game sound toggle controls all three files. No generated or browser-synthesized sound effects are used.
